# がんばりバンク 🏦

未就学〜低学年の子ども向けの、**1ファイルWebアプリ（PWA）**です。
おべんきょう（ことば・かず・カタカナ・なぞり書き）や おてつだいで「がんばりポイント」がたまり、YouTube・Switchの時間やごほうびと交換できます。

**非エンジニアの親が、AIと一緒に作りました。**

👉 **デモ（そのまま遊べます）**: https://ayatsukinoyou.github.io/ganbari-bank/

---

## できること
- ✏️ **おべんきょう**：ことばあそび／かず・けいさん／カタカナ／ひらがな・カタカナのなぞり書き（ジャンルごとにレベル1〜3で少しずつ難しく）
- 🧺 **おてつだい**：おかたづけ等でポイント（保護者が自由に編集）
- 🎁 **ごほうび**：YouTube・Switchの時間、実物ごほうびと交換（ページ制ポイント経済）
- ⏰ **やさしいタイマー**：時間になったら👻おばけが来る段階式。スリープ防止つき
- 🏅 **ずかん**：がんばりでシールが集まる
- 🔒 **保護者メニュー（PINロック）**：ポイントのルール・ごほうび/おてつだいの編集・交換履歴のとりけし・がんばり記録

## つかいかた
1. 上のデモURLを開く（スマホ/タブレット/PC どれでもOK）
2. 右上の ⚙️ → PIN（さいしょは `0000`）→ **👶 おなまえ** で子どもの名前を設定
3. ホームからおべんきょう・おてつだいスタート！

## プライバシー
- **データはすべて、その端末のブラウザ（localStorage）の中だけ**に保存されます。
- サーバーには何も送信されません。ポイントも記録も、外に出ません。

## 技術メモ
- 依存ライブラリなしの素の HTML / CSS / JavaScript（1ファイル）＋ PWA（Service Worker でオフライン対応）
- 音声は Web Speech API、なぞり書きは Canvas の自作判定エンジン
